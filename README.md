Spring Boot DevTools
SpringBootDevTools is an auxiliary tool to improve development
efficiency. This will automatically restart the web application. For
example, suppose you modified and saved your Java code. In this
case, the changes do not take effect until the web application is
restarted. By installed SpringBootDevTools, you can automatically
restart the web application at the moment the file is saved. This
reduces reboot operations and improves development efficiency.

Thymeleaf
Thymeleaf is an HTML template engine used by SpringBoot as
standard. The Template Engine is the ability to synthesize HTML
templates and data into HTML. For example, a Java list can be
looped and displayed as a list.
Before Thymeleaf was used, JSP was a popular template engine. JSP
puts Java code in HTML. As a result, HTML is very unreadable.
Thymeleaf improves this point, making HTML much easier to
understand.
